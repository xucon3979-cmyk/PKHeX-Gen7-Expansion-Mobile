# PKHeX Gen7 Expansion Mobile v0.7.0 — changes and limits

Based on [santacrab2/PKHeXMAUI](https://github.com/santacrab2/PKHeXMAUI) (pinned original interface and bundled assets) with [Aqua-0 PKHeX.Core v1.0](https://github.com/Aqua-0/PKHeX/releases/tag/v1.0).

## v0.5 — Expansion support
- Retains form, Move, Ability, Item and Species changes already present in Aqua-0 Core.
- Retains the v0.4 persistent PKHaX toggle and disables original MAUI update-check messages.
- All editor tabs use an offline sprite selection service. It indexes existing `a_*.png` editor artwork and `b_*.png` Box artwork, including shiny and supported forms.
- A new Expansion form without matching artwork shows its base form instead of a broken image. The Box label includes the form number.
- If Core exposes more form IDs than names, the picker uses **Expansion Form N**.
- **Custom art is NOT supplied for Mega Greninja and other unsupported fan forms.** Adding actual unique sprite art still requires an appropriately licensed new image.

## v0.6 — Safe Save
- On **opening a supported save file**, creates a copy of the exact imported bytes in private Android app storage. If this fails, importing is cancelled.
- On **Export Save**, clones and serializes the current save, writes a private pre-export snapshot and verifies that a Gen7 USUM save can be re-read with valid checksums. If validation fails, the file is not exported.
- **Settings → Restore save backup** opens a selected backup inside the editor without overwriting the original file. Export Save creates the recovered `main` file separately.
- Backup history retains the 20 latest saves. **Warning:** uninstalling the app can remove its private backups! Export important copies elsewhere first.
- The `tests/Gen7RoundTrip.csproj` command-line test creates a *synthetic* USUM save, writes Mega Greninja form 3 with an Expansion Ability/Item/Move and checks reading it back and its checksums. This does **not** prove a player's actual ROM-hack save can be edited without risk.
- No user `main` was uploaded for this change, so real-world integration testing is pending.

## v0.7 — Android stability and performance
- Async Android document picker streaming avoids relying on Android's `content://` path being readable with `File.ReadAllBytes`.
- Persistent **Show Box legality markers** option, off by default to avoid expensive legality checks on every sprite refresh.
- On-device managed crash/error logs; **Settings → Export crash log** lets users export a text file. No automatic log upload.
- A **signed Android APK** is produced and smoke-tested on an emulator before delivering a download link. The smoke test confirms the app process remains alive; it does not test every screen or save operation.

## Updating without uninstalling
Android permits an in-place update **only if the Android package ID and APK signing certificate match**.

The GitHub workflow accepts four **repository Actions secrets** (Settings → Secrets and variables → Actions):
- `ANDROID_SIGNING_KEYSTORE_B64`: base64-encoded Android keystore file bytes
- `ANDROID_SIGNING_ALIAS`: key alias
- `ANDROID_SIGNING_STOREPASS`: keystore password
- `ANDROID_SIGNING_KEYPASS`: private-key password

If all are configured, future APKs use the same key, allowing in-place updates among those releases. **Do not commit or share the keystore or passwords.**

If these secrets are not configured, the workflow makes a fresh temporary Debug key on every run. Those builds cannot be installed over the prior APK; private app data may be lost when uninstalling. The existing v0.4 APK used a temporary key, so configuring a new stable key still requires **one last reinstall**.

## How to build and download
Go to [GitHub Actions](https://github.com/xucon3979-cmyk/PKHeX-Gen7-Expansion-Mobile/actions/workflows/android-maui-expansion.yml), select a run where **both jobs succeed**, then download the artifact **PKHeX-MAUI-Gen7Expansion-v0.7.0-Signed-APK**. Extract the ZIP to obtain the APK.

**Always back up your save externally before testing new versions.**
